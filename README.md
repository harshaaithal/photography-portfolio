# Harsha — Photography

This is a static one-page portfolio preview. It uses temporary Unsplash sample photos and marks every image slot so they are easy to replace.

## Replace the sample photos

Open the `images` folder and replace these files with your own edited JPEGs, keeping the exact filenames:

- `landscape-hero.jpg`
- `landscape-01.jpg`, `landscape-02.jpg`, `landscape-03.jpg`
- `product-01.jpg`, `product-02.jpg`, `product-03.jpg`
- `travel-01.jpg`, `travel-02.jpg`, `travel-03.jpg`

The page crops images to fit each frame. Keep a copy of your original exports; replacing a file with the same name is the quickest way to update the page.

## Personalize the page

- In `index.html`, replace `your@email.com` in both the link and visible text with your real contact address.
- Update the About copy, image captions, or section names in `index.html` whenever your collection changes.
- The sample-image labels can be removed after the placeholder photographs are replaced.

## Image source

The temporary sample images are from Unsplash and are used under the Unsplash License. Replace them with your own work before treating this as your finished portfolio.
