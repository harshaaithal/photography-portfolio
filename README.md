# Harsha — Photography

This is a static portfolio page for landscape and travel photography. Product work is marked as coming soon until a suitable set is ready.

## Photos

The page uses 12 edited JPEG exports in `images/portfolio/`: five landscape photographs and seven travel photographs. The first landscape photograph also appears in the hero.

Web copies are limited to 2400 pixels on the long edge, converted to sRGB, and saved without EXIF metadata. The Lightroom exports are left untouched. Keep the image paths in `index.html` relative so the page also works under the GitHub Pages project subpath.

Update image descriptions and captions in `index.html` when replacing or adding photographs. Do not publish private location or contact details without checking them first.
